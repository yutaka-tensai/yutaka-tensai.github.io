# Sleep Cycle Web

Sleep Cycle のような睡眠記録アプリを、Web だけで作ったものです。
インストール不要・完全オフライン動作・データは端末内のみ。

**公開URL: https://yutaka-tensai.github.io/sleep/**

## 機能

| 機能 | 内容 |
|---|---|
| スマートアラーム | 設定時刻までの猶予（10〜60分）の中で、眠りが浅くなった瞬間に起こす |
| 睡眠グラフ | 覚醒 / 浅い睡眠 / 深い睡眠 の推移を曲線で表示 |
| 睡眠の質スコア | 睡眠効率・深睡眠の割合・中途覚醒・睡眠時間から 0〜100% を算出 |
| いびき検出 | 低域が支配的で呼吸周期に合う音を検出し、いびき時間を集計 |
| いびき・寝言の録音 | 大きな音を 6 秒だけ自動録音して翌朝に再生（1晩あたり最大14件） |
| 入眠サウンド | 雨・波・焚き火・扇風機・夏の夜・ホワイト/ピンク/ブラウンノイズ・ドローン（フェードアウト付き） |
| アラーム音 | 5 種類を合成音で生成。45 秒かけて徐々に音量が上がる |
| インテリジェントスヌーズ | 押すたびにスヌーズ間隔が半分になる |
| 睡眠メモ | 「コーヒー」「お酒」などのタグと睡眠の質の相関を統計に表示 |
| 目覚めの気分 | 5 段階で記録 |
| 統計 | 7/30/90日の平均睡眠時間・質・就寝/起床時刻・生活リズム・曜日別・睡眠負債 |
| データ管理 | JSON でエクスポート／インポート、全削除、サンプルデータ生成 |
| PWA | ホーム画面に追加でアプリのように起動、オフライン動作 |

## 使い方

1. 起きたい時刻と「スマート起床の幅」を設定する
2. 端末を枕元（マットレスの上か枕の横）に、画面を上にして置く
3. 「眠りを記録する」を押してそのまま眠る

充電しながらの使用を推奨します。

## 仕組み

- **センシング** — マイクの音圧（100ms ごとの RMS）と加速度センサーの振動を 30 秒ごとの「エポック」にまとめ、活動量（0〜1）を算出します。ノイズフロアは直近 60 秒の音圧の 20 パーセンタイルとして推定し、エアコンなどの定常音は「静けさ」として扱います。
- **睡眠 / 覚醒の判定** — 前後のエポックに重みを付けた加重和で判定します（Cole-Kripke 法の考え方を単純化したもの）。
- **眠りの深さ** — その夜の中での相対的な「静けさ」に、約 90 分の睡眠周期と「深い睡眠は夜の前半に偏る」という性質を掛け合わせて推定します。端末やマイク感度の差を吸収するため、絶対値ではなく夜ごとの相対値で正規化しています。
- **いびき判定** — 0.4〜3.6 秒の長さで低域（60〜500Hz）が 55% 以上を占める音が、呼吸として妥当な間隔（1.2〜9 秒）で 3 回以上続いたときにいびきとみなします。
- **スマートアラーム** — 猶予時間に入ってから、推定した深さがしきい値を下回った瞬間に鳴らします。しきい値は設定時刻に近づくほど緩くなり、最終的には設定時刻ちょうどに必ず鳴ります。

## Web アプリとしての限界

ネイティブアプリと違い、以下はブラウザの制約でできません。

- **画面を消したり他のアプリに切り替えたりすると、記録もアラームも止まります**（バックグラウンド実行ができないため）。アプリを開いたまま置いておく必要があります。
- OS のアラーム権限・マナーモードを無視した鳴動・ヘルスケア連携・Apple Watch 連携はできません。
- 睡眠段階の推定は体動と音からの推測です。医療目的には使えません。

## プライバシー

音声解析はすべて端末内で行われ、録音・睡眠データを含め、外部に送信されることは一切ありません。保存先は IndexedDB と localStorage です。

## 構成

```
sleep/
├── index.html
├── manifest.webmanifest / sw.js   PWA
├── css/app.css
└── js/
    ├── app.js       画面遷移・記録の開始/終了・スマートアラーム
    ├── tracker.js   マイク/加速度センシング、いびき検出、録音
    ├── stats.js     睡眠段階の判定・スコア計算・統計
    ├── audio.js     アラーム音と入眠サウンドの合成（Web Audio）
    ├── chart.js     Canvas によるグラフ描画
    ├── store.js     IndexedDB / localStorage
    └── utils.js
```

ビルド不要のバニラ JavaScript（ES モジュール）です。
