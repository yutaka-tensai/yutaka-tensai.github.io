# 朝6時のマーケットレポート

毎朝6時（日本時間）までに、前営業日のマーケットを「小学生にも分かる言葉」でまとめたレポートを公開します。

- 公開URL: `/reports/`
- 各号: `reports/YYYY-MM-DD.html`
- スタイル: `css/report.css`（全号で共通）

## 毎号の構成

1. **3行まとめ** — これだけ読めばその日が分かる
2. **いまの数字** — 株価・金利・為替・商品の終値テーブル
3. **いま何が起きているの？** — その日の主役になっているストーリー（2〜3本）
4. **今週の予定** — 相場を動かすイベントのカレンダー
5. **ドル円はロング？ショート？** — 結論 → 円安材料と円高材料の対比 → 理由 → 目安の水準
6. **どの金融商品を買えばいいの？** — レポートの内容から素直に導ける具体的な商品
7. **最後に、いちばん大事なこと** — この見立てが外れる条件と、免責
8. **むずかしい言葉じてん** — 本文に出た専門用語の解説

## 書くときのルール

- 一文は短く。専門用語を使ったら、その場か「言葉じてん」で必ず言い換える
- 数字は必ず日付とセットで書く（「8月28日の終値」など）
- 相場観は結論から先に書き、**外れる条件も同じ強さで書く**
- 参考にした報道は、フッターに媒体名・見出しで明記する
- 「必ず儲かる」とは絶対に書かない。免責は毎号入れる

## 新しい号の追加手順

1. 直近の号をコピーして `reports/YYYY-MM-DD.html` を作る
2. 本文を差し替える
3. `reports/index.html` の一覧の先頭に、日付・見出し・リード文を追加する
