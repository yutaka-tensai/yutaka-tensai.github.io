# Camera Stats

写真の EXIF（撮影情報）を読み取って、**カメラ・レンズ・F値・焦点距離・ISO・撮影時間帯**を
グラフで可視化するツールです。ビルド不要の静的サイトで、GitHub Pages にそのまま置けます。

公開 URL: `https://yutaka-tensai.github.io/camera/`

## Instagram との関係について（重要）

**Instagram に投稿された写真から機材情報を取り出すことはできません。**

- Instagram はアップロード時に画像から EXIF を削除します。投稿画像をダウンロードしても
  F値やレンズ名は残っていません。
- Instagram Graph API が返すのは投稿 ID・キャプション・画像 URL などで、撮影情報は含まれません。

そのためこのツールは、**Instagram に投稿する前のオリジナル写真**（カメラから取り込んだファイル）を
読み込んで集計します。投稿している写真をそのまま選べば、実質的に「Instagram の作風」の可視化になります。

補助的に、Instagram の「データをダウンロード」で取得できる JSON も読み込めます。ただし取得できるのは
投稿日時と、キャプションに書かれた機材表記（`35mm F1.8` など）からの推定値までです。

## 使い方

1. `https://yutaka-tensai.github.io/camera/` を開く
2. 写真をドラッグ＆ドロップ、または「フォルダごと選ぶ」で一括読み込み
3. グラフのカメラ／レンズをクリックすると、その機材だけに絞り込み
4. 「CSV でダウンロード」で集計結果を書き出し

動作を確かめるだけなら「サンプルで試す」でダミーデータを表示できます。

## フォトカードを作る

一覧表のサムネイルをクリックすると、写真と撮影データを組み合わせた1枚のカード画像を作れます。
Instagram に投稿する用の画像として PNG で書き出せます。

切り替えられる項目:

- **向き**: 縦 4:5（1080×1350） / 正方形 1:1（1080×1080） / 横 4:3（1440×1080）— すべて Instagram 対応比率
- **配色**: ホワイト / ブラック / クリーム / ネイビー
- **フォント**: ゴシック / 明朝 / 等幅 / 欧文セリフ
- **アクセント色**: 好きな色を指定（区切り線に反映）
- **タイトル**: 任意のテキストを追加
- **載せる情報**: レンズ名・撮影日の表示切り替え

写真の縦横比に合わせてカードの向きが自動で選ばれ、写真は切り抜かずに全体が入ります。
**元の写真ファイルは書き換えません。** canvas 上で新しい画像を組み立てて保存します。

## プライバシー

読み込んだ画像はすべてブラウザ内（JavaScript）で処理され、サーバーには一切送信されません。
アップロード先も外部 API も存在しません。GPS 情報を含む写真がある場合は枚数を表示します。

## 構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面 |
| `css/app.css` | スタイル（ライト／ダークの両対応） |
| `js/exif.js` | 依存なしの EXIF パーサ（JPEG の APP1 を走査し、無ければ `Exif\0\0` を総当たり検索） |
| `js/charts.js` | 依存なしの棒グラフ描画 |
| `js/instagram.js` | Instagram エクスポート JSON の読み取り |
| `js/card.js` | フォトカードの合成と PNG 書き出し |
| `js/app.js` | 集計・描画・フィルタ・CSV 出力 |

外部ライブラリ・ビルドツールは使っていません。ファイルを置くだけで動きます。

## 対応フォーマット

### 撮影データ（カメラ・レンズ・F値など）

JPEG は確実に読めます。HEIC / TIFF / WebP / 一部の RAW も、EXIF ブロックがそのまま埋め込まれていれば
読めます（コンテナ解析はしていないため、読めない場合があります）。読み取れなかった枚数は画面に表示されます。

### 画像そのものの表示（サムネイル）

**HEIC（iPhone の標準形式）は Chrome / Edge が表示できません。** これはブラウザ側の制約で、
このツールでは変えられません。撮影データの集計には影響しないため、グラフや一覧表は通常どおり動きます。

表示できない場合は、一覧表のサムネイル欄に拡張子のバッジ（`HEIC` など）を出します。
なお EXIF 内に JPEG サムネイルが埋め込まれているファイル（一部の RAW / HEIC）は、それを取り出して表示します。

iPhone の写真を画像つきで見たい場合:

- iPhone の **[設定] → [写真] → [MacまたはPCに転送]** を「自動」にすると、パソコンへ取り込むときに JPEG に変換されます
- これから撮る写真は **[設定] → [カメラ] → [フォーマット] → 「互換性優先」** で JPEG になります
