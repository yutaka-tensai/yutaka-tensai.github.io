まず知っておいてほしいこと

Instagram に投稿された写真からは、カメラ・レンズ・F値を取り出せません。 Instagram はアップロード時に EXIF（撮影情報）を削除しますし、公式 API も返しません。 そのため、このアプリはInstagram に上げる前のオリジナル写真を読み込んで集計します。 投稿している写真をそのまま選べば、あなたの「Instagram の作風」がそのまま数字になります。

  1. 写真を集める — Instagram に投稿した元データ（カメラから取り込んだファイル）をフォルダにまとめます。
  2. 読み込む — 上のエリアにドロップするか「フォルダごと選ぶ」で一括読み込み。
  3. 眺める — 機材・F値・焦点距離・ISO・撮影時間帯が自動で集計されます。グラフをクリックすると絞り込めます。

Instagram の「データをダウンロード」で取得した JSON も読み込めます。ただし取り出せるのは投稿日時と、 キャプションに書かれた機材表記（35mm F1.8 など）の推定値までです。

RAW（.ARW / .NEF / .CR2 / .CR3 / .DNG / .ORF / .RW2 / .RAF など）と HEIC にも対応しています。 画像そのものの表示には、RAW に埋め込まれたプレビューを使います。読み取れなかった枚数は結果画面に表示されます。
